# Windows11-Upgrade
A short and sweet Powershell script to Upgrade Windows PCs to Windows 11 25H2

# Usage
> [!NOTE]
> This script doesn't take any parameters, and will fail to execute if any are passed to it.

Download Windows11-Upgrade.ps1 and run as an Administrator.

> [!IMPORTANT]
> If you are trying to run the script, and it is failing with "Execution Policy restriction." You will need to change your system Execution Policy, or bypass it this time.\
> Open CMD as administrator and run `powershell.exe -ex Bypass -file .\Windows11-Upgrade.ps1`\
> Or, see how to change to change it for your system [here](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies?view=powershell-7.6#change-the-execution-policy)
